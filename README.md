# Social Credit

*Bureau of Civic Standing · Est. 2026*

A satirical website where friends rate each other. You commend people for merits ("Brought snacks", +20) and report infractions ("Hit reply-all", −15). Each citizen's portrait becomes a **3D face** you can rotate, and their standing changes how the site treats them.

One citizen is beyond reproach: **The Creator**, whose score is permanently ∞.

## Features

- **Photo → 3D face.** In the browser, MediaPipe Face Landmarker finds 478 facial landmarks. Those become MediaPipe's canonical 904-triangle face mesh (the eyes and mouth are filled), textured with the photo and rendered in Three.js with custom shaders. You can drag to rotate it. Detection runs on the device, so only the cropped portrait and the landmark mesh are uploaded.
- **Webcam or upload.** You can take a selfie or drop in a photo. If no face is found, the Bureau "approximates" with a sculpted relief.
- **The face reflects standing.** The elite get a golden halo and rising motes. Ordinary citizens get a cool hologram. The disgraced are desaturated, flicker and glitch. Every rating sends a green or red ripple across the face.
- **Live feed and registry.** Rankings, 24-hour deltas, a score-history sparkline, and an official record of every change.

## What happens with good or bad credit

Everyone starts at **1,000**. Your tier decides how much *your* opinion is worth and how pleasant the site is for you.

| Tier | Score | Rating weight | Ratings/day | What it does |
|---|---|---|---|---|
| ∞ **The Creator** | ∞ | ×3 | unlimited | Score fixed. Criticism bounces back onto the critic at 2×. Praise earns the praiser +5. Can issue site-wide decrees and grant amnesty. |
| **AAA** Exemplary Citizen | 1300+ | ×2 | 30 | Golden halo. Anyone who reports you pays a −5 *envy tax*. |
| **AA** Model Citizen | 1150–1299 | ×1.5 | 20 | |
| **A** Good Standing | 1000–1149 | ×1 | 12 | |
| **B** Under Observation | 850–999 | ×0.75 | 8 | A small eye follows your cursor around the site. |
| **C** Cause for Concern | 600–849 | ×0.5 | 5 | The site turns grayscale. Pages "load slower" (bandwidth reallocated to better citizens). |
| **D** Persona Non Grata | 0–599 | ×0.25 | 3 | You may only praise, never criticise. Anyone who praises you pays a −5 *fraternization fee*. Your face glitches. The site is set in Comic Sans. |

Other rules:

- **Re-education.** Citizens below 1,000 can take a three-question loyalty quiz every 12 hours. All three correct earns +40. ("The Bureau's algorithm is best described as: *Flawless*.")
- **Cooling off.** You can rate the same person once every 30 minutes. Self-rating is not allowed.
- **Refusing biometrics** costs −50.

All the rules live in [`lib/rules.js`](lib/rules.js). Change the numbers, add merits and infractions, or write new quiz questions there.

## Who becomes The Creator

The **first account to enroll** becomes The Creator. To reserve the title before going public, set `CREATOR_USERNAME`:

```bash
CREATOR_USERNAME=yourname npm start
```

## Run it

Requires Node 18+.

```bash
npm install     # also downloads the 3.7 MB face model into models/ (optional; falls back to Google's CDN)
npm start       # http://localhost (port 80)
```

Environment variables:

| Variable | Default | Meaning |
|---|---|---|
| `PORT` | `80` | HTTP port |
| `DATA_DIR` | `./data` | Where the JSON database and uploaded portraits live |
| `CREATOR_USERNAME` | (unset) | Reserve The Creator title for this username |
| `TRUST_PROXY` | (unset) | Set when running behind a reverse proxy / HTTPS terminator, so cookies get `Secure` |

Port 80 is a privileged port on Linux, so either run `sudo npm start`, or allow Node to bind it once with `sudo setcap 'cap_net_bind_service=+ep' "$(command -v node)"`. macOS and Windows allow it without extra steps. To use another port: `PORT=3000 npm start`.

The webcam only works on `https://` or `localhost`. That's a browser rule.

## Design choices worth knowing

- **Opt-in only.** You can only upload *your own* face, during your own enrollment. Nobody can create a profile of someone else, so everyone on the registry chose to be there.
- **No free-text ratings.** Ratings come from a fixed catalogue of merits and infractions, which keeps the game funny rather than mean.
- **Every rating is attributed.** The feed shows who rated whom.

## How it's built

- `server.js`: Express API (accounts, ratings, re-education, decrees) and static hosting
- `lib/rules.js`: tiers, weights, merits, infractions, quiz
- `lib/store.js`: a small JSON-file database with atomic writes, enough for a friend group. Swap in SQLite or Postgres if it grows.
- `lib/auth.js`: scrypt password hashing, session cookies, login rate limiting
- `public/js/face3d.js`: the Three.js holographic face renderer (custom GLSL)
- `public/js/scan.js`: MediaPipe detection, face crop, webcam capture
- `public/js/face-topology.js`: generated by `npm run build:topology` from MediaPipe's canonical mesh
- `public/js/app.js`: hash router and views. No build step: ES modules plus an import map.

It's satire. Please don't build this for real.
